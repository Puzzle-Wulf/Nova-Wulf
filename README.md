# NovaWulf — Discord Bot Dokumentation

Dies ist das **öffentliche Dokumentations-Repository** für NovaWulf, nicht das Quellcode- oder Build-Repository des Bots.

## Dokumentationswebsite

Die statische, serverunabhängige Website liegt unter [docs/index.html](docs/index.html). Sie erklärt **alle im geprüften Quellstand registrierten Slash-Befehle**, Einrichtung und Rollen, Events, Übersetzung, Nachrichtenstudio, Moderation, Assets, Emojis, Sticker, Medien, Chatbot, Service-Katalog und ASF.

**GitHub Pages:** Im Repository unter **Settings → Pages → Build and deployment → Deploy from a branch** den Branch **main** und das Verzeichnis **/docs** wählen. Danach ist die Website unter `https://puzzle-wulf.github.io/Nova-Wulf/` erreichbar, sofern GitHub Pages für die Organisation aktiviert ist.

## Veröffentlichungsregel

- Nur öffentliche Benutzerdokumentation (HTML/CSS/JS, Texte, Bilder, Anleitungen, geprüfte Befehlsreferenz).
- Keine privaten Python-Quellen, Zugangsdaten, internen Konfigurationen, Datenbanken, Testberichte, Installationspakete oder Bot-Builds.
- Dokumentierte Befehle stammen aus einem überprüften privaten Implementierungsstand. Nicht aktivierte, bloß geplante Funktionen werden **nicht** als verfügbar dargestellt.
- Dokumentationsänderungen dürfen nach Quellenprüfung veröffentlicht werden; Bot-Releases werden hier **nicht** verteilt.
- Die Versions- und Aktualitätsangabe der Dokumentation bezeichnet die geprüfte Codebasis, nicht automatisch den Live-Discord-Status.
